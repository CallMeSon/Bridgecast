      Questions,answered.

      What do I need to run it?

      A Windows 11 PC with a second display. PowerPoint is needed to import .ppt and .pptx files and for Native playback. The NDI Runtime is never bundled; it is loaded from your own installation.

      Does it run on Linux?

      Linux (X11) plays slide shows through LibreOffice Impress. On Wayland, decks play as Vector or Still images. Linux is not yet verified end to end.

      Does it work offline?

      Yes. Only web decks need the network, while the page loads and plays.

      Does it change my original files?

      No. The imported file is never modified. Edit in PowerPoint works on a copy.

      What if PowerPoint or a web page fails?

      The output keeps the last good frame or shows the PNG of the same slide. It never goes black and never shows the desktop.

      Can speakers use a clicker?

      Yes. A clicker's arrow keys move Next and Previous.

      Which files can I import?

      pptx, ppt and pdf files, plus web pages. Every deck is also converted to PNG slides as a fallback.

      Is it tested at real events?

      Not yet. The Windows features (PowerPoint playback, window capture and network output) are built but have not been field-tested on a real event PC.
