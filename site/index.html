What it does

One Program, always on air

One output, one take at a time. Next, Freeze, Black and KV are states you can read at a glance. The audience sees a slide, a held frame or the standby card, never the desktop.

Keys and clicker first

Space or the arrow keys take the next slide, and a presentation clicker works the same way. F freezes, B goes black, K shows the key visual, and N and D jump between sections and decks.

Your PowerPoint, as it plays

PowerPoint decks can play as a real slide show, with animations, video and sound (Windows with PowerPoint). PDFs and images are drawn sharp and run offline.

Web pages as decks

A Canva presentation, a video page or any https page can be a deck. It goes on air only once it is ready, and if the page fails the output holds the last good frame.

Network output

Send the Program over the LAN with OMT or NDI, for vMix, OBS and other receivers. The frame rate and canvas size are set per machine, or per event.

Events, not loose files

Each event keeps its decks, sections and key visual together. Home lists them, with the event that is on air first.

Status. Bridgecast is built for Windows 11. The parts that only run on Windows, such as PowerPoint, window capture and network receivers, are still being field-tested. Check the notes before you rely on them in a live show.
