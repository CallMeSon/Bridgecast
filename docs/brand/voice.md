# Bridgecast voice

## Principles

- State first. Say what is happening, then what to do.
- Use operator words: Program, Hold, Black, Take, Next, Deck, Event.
- Brief and calm. No exclamation marks.
- Buttons are verbs.
- Never claim "zero latency", "unbreakable" or "professional grade" without a measurement.

## Casing

- The product name is exactly "Bridgecast".
- Sentence case everywhere.
- Status tags in mono caps: ON AIR, NEXT, HOLD.

## Examples

| Where | Copy |
| --- | --- |
| Status | On air |
| Web deck failure | The page stopped responding. Holding the last frame. |
| NDI missing | NDI is not installed. Install it to send over the network. |
| Empty library | No decks yet. Drop a PowerPoint, PDF or video folder here. |

## Tagline

From slide to screen, live.
