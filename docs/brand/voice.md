# Bridgecast voice

## Principles

- State first. Say what is happening, then what to do.
- Use operator words: Program, Hold, Black, Take, Next, Deck, Event.
- Brief and calm. No exclamation marks.
- Buttons are verbs.
- Never claim "zero latency", "unbreakable" or "professional grade" without a measurement.
- Say what still works when something fails, not only what broke.
- Never blame the operator and never joke. No puns on bridges.
- Labels are one to three words. A message is one sentence, two at most.
- Name things the operator's way, not the system's: not "stream pipeline" or "frame buffer".

## Casing

- The product name is exactly "Bridgecast". Never "BridgeCast", "Bridge Cast" or "BC".
- Sentence case everywhere.
- Status tags in mono caps: ON AIR, NEXT, HOLD.
- A confirmation repeats the verb: "Delete deck", not "OK".
- Numbers stay numerals: "Slide 4 of 31", "1920 × 1080", "30 fps".

## Examples

| Where | Write | Do not write |
| --- | --- | --- |
| Status | On air | Currently broadcasting to output |
| Web deck failure | The page stopped responding. Holding the last frame. | Oops! Something went wrong |
| NDI missing | NDI is not installed. Install it to send over the network. | Failed to load NDI runtime |
| Empty library | No decks yet. Drop a PowerPoint, PDF or video folder here. | Nothing to see here! |

One sentence for the product: Bridgecast is an operator console that puts slides, PDFs, video and web pages on a screen or across the network from a single window.
