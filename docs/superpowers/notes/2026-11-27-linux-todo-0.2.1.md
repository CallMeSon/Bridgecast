# Linux: rilis 0.2.1

Tanggal: 2026-11-27. Rilis 0.2.1 dibuat dulu di Windows (`npm run release:win`). Rilis belum
selesai sampai artefak Linux ikut di `v0.2.1`.

## Langkah

- Ikuti langkah install di `2026-11-26-linux-todo-0.1.16.md` (npm install-scripts, koffi).
- Checkout `main` di tag `v0.2.1`, tree bersih.
- Uji: `npx vitest run`, lalu
  `xvfb-run -a -s '-screen 0 2560x1440x24' npm run test:e2e:media` dan `npm run test:e2e:media-omt`
  (butuh `ffmpeg`).
- `npm run release:linux`, lalu `node scripts/release.mjs --check 0.2.1`.

## Perubahan yang belum diuji di Linux

- Video dikirim lewat `slide://` dengan stream rentang utuh (dulu dibatasi 4 MB). Klip MP4
  besar tanpa faststart sekarang bisa diputar.
- Zoom dan pan di monitor Program, minimap dihapus.
- Meter suara Program, suara di jendela operator saat tanpa output, tombol Monitor.
- Slider seek video (Radix Slider) dan panah pan zoom (klik = langkah, tahan = geser pelan).
- Tambahan e2e: `npm run test:e2e:media-omt` (butuh `ffmpeg`).
