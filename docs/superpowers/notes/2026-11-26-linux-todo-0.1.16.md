# Linux: yang harus dikerjakan saat pindah ke Linux (0.1.16)

Tanggal: 2026-11-26. Rilis 0.1.16 baru berisi installer Windows. Fitur media player dan zoom
preview Prepare dibuat dan diuji di Windows saja. Kodenya tidak punya cabang per platform, tapi
belum pernah dijalankan di Linux.

## 1. Uji di Linux

- `npm ci`, lalu `npm run typecheck` dan `npx vitest run`.
  - Di Windows ada 2 test yang gagal karena path (`src/main/slideshow/libreoffice-engine.test.ts`
    `loBridgePath`, dan `src/main/web/host-rules.test.ts` `isAppPageUrl`). Di Linux keduanya
    seharusnya lolos; kalau gagal, cek.
- Media player: `xvfb-run -a -s '-screen 0 2560x1440x24' npm run test:e2e:media`
  (butuh `ffmpeg` di PATH; tanpa ffmpeg suite-nya di-skip dengan exit 0, jadi pastikan
  terpasang: `sudo apt install ffmpeg`).
- Zoom preview Prepare: `xvfb-run -a -s '-screen 0 2560x1440x24' npm run test:e2e:web`.
- Smoke: `xvfb-run -a -s '-screen 0 2560x1440x24' npm run test:e2e`.
- Cek manual (`npm run dev`, X11):
  - Import file `.mp4` (H.264/AAC) dan `.webm`, Take, lalu Play/Pause/seek/Restart/Loop dari
    operator. Layar HDMI hanya menampilkan video.
  - Suara video keluar di perangkat yang dipilih (Settings, Sound), volume deck dan master
    berlaku, Mute all membisukan.
  - OMT/NDI: video media tampil di penerima (vMix/OBS) dan suaranya ikut rute Network.
  - Jendela Prepare: Ctrl+wheel/pinch zoom di titik pointer, drag/wheel/panah geser,
    Ctrl+= / Ctrl+- / Ctrl+0.

## 2. Rilis Linux untuk 0.1.16

- **npm 11 memblokir install script** (`npm install-scripts ls`). Setelah `npm ci`, Electron dan
  esbuild tidak terpasang lengkap. Di Windows dijalankan manual (tanpa mengubah file yang
  di-track): `node node_modules/electron/install.js`, `(cd node_modules/esbuild && node install.js)`,
  `(cd node_modules/koffi && node ./cnoke.cjs -P . -D src/koffi --prebuild --release)`. Cek
  `node -e "require('koffi')"` sebelum build.

- Di Linux, checkout `main` di commit rilis 0.1.16 (tag `v0.1.16`), tree bersih.
- `npm run release:linux` (lewat `scripts/release.mjs --linux --publish`): build AppImage + deb
  dan upload ke release `v0.1.16` yang sudah ada.
- Lalu `node scripts/release.mjs --check 0.1.16`: harus bilang release membawa artefak Windows
  dan Linux.
